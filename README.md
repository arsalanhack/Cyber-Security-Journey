# Cyber-Security-Journey
The Documentation of my Journey to Cyber-Security

A public log of my self-study journey into cybersecurity — documenting my progress through **Jeremy's IT Lab** and **The Linux Command Line** by William Shotts, on my way toward TryHackMe, Hack The Box, and eventually a master's in cybersecurity.

## Why this repo exists

I'm using this summer to build a strong foundation in Linux and networking fundamentals before diving into hands-on security labs. This repo is where I track what I learn, session by session — partly for accountability, partly as a reference I can look back on.

## What's inside

- **`jeremys-it-lab/`** — Daily journal entries following Jeremy's IT Lab course, organized by day.
- **`linux-command-line-book/`** — Chapter-by-chapter notes from *The Linux Command Line* by William Shotts, plus a running cheat sheet of commands I've learned.

## How entries are organized

Each day/chapter has its own `journal.md`. I don't always finish a day or chapter in one sitting, so entries are broken into dated sections within the same file — you can follow the thought process over time, not just the final result.
