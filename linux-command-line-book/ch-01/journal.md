**Chapter 1 - What is the shell?**

**2026-07-31**

The Course starts on this day.

Before starting this course I already had a bit of knowledge about linux and its command line. I already knew some of the basic commands like: cd, ls, mkdir, rmdir, etc.

In my own words:
- A Terminal Emulator is an application you type commands into.
- A Shell is the program that reads and executes the commands. e.g: Bash, zsh.
- A Virtual console is a text only terminal session. There is no GUI, just a black screen with text, where you write commands and the operating system executes.
- File system of Linux and MacOS is different from Windows. The files are stored in a tree like pattern called the hierarchical directory structure. root-directory -> files, sub-directories/
- No separate tree in Linux. Linux has only one file system tree, one unified name space rooted at '/'. Additional file systems are mounted somewhere within that namespace.

Commands I learned:
- '$ date'    # Show date
- '$ cal'   # Show calendar
