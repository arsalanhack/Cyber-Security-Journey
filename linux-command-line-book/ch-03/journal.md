The less program

Today I learned about the less program. This part of the chapter was very interesting. I learned many new things about Linux and a new command.

In my own words:
- The text file(.txt) is very important to Linux and other Unix based operating systems because crutial files like configuare files, scripts etc are stored in .txt files for human and machine readability.
- The text file is an ASCII text document.
- The less program is a simple text viewing programing with the ability to go forwards and backwards, up and down etc.
- I found out that the less command is actually a program that alredy sits on my computer.
- Less is the newer version of an older text file viewing program called 'more'. Less is more.

Commands I learned:
- 'less filename'    # Shows contents of file in a book like format.
